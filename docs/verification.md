# Результаты реальной проверки

Проверка выполнена 2026-10-29 на CachyOS, Wayland/Hyprland.

## Оборудование

- CPU: Intel Core i5-11260H, 12 потоков
- GPU: NVIDIA GeForce RTX 2050, 4 ГБ VRAM (CUDA)
- RAM: 16 ГБ
- Ядро: 6.18.55-2-cachyos-lts

## Модель

- Ollama 0.40.13 установлена в `~/.local`, запущена пользовательским
  `systemd --user` сервисом.
- Модель: `qwen2.5:3b-instruct` (1.9 ГБ).
- `amadeus --benchmark`: первый токен 51.2 мс, 113 токенов, 51.0 ток/с,
  загрузка на RTX 2050.
- Реальный диалог через CLI и GUI работает. 3B-модель иногда ошибается в
  фактах; для качества стоит проверить 7B при достаточной RAM/VRAM.

## Голос

- whisper.cpp собран из исходников, установлен в `~/.local/bin/whisper-cli`.
- Модель: `ggml-small.bin` (466 МБ).
- Piper 2023.11.14-2, голос `ru_RU-irina-medium.onnx`.
- `VoicePipeline.status()`: запись, STT, TTS и плеер — все OK.
- Проверка TTS → WAV → STT: синтезировано «Привет, это проверка русского
  голоса Amadeus», распознано «Привет, это проверка русского голоса Амадес».
- Запись с микрофона (parecord, 2 с) создаёт корректный WAV; распознавание
  окружающего звука работает. Разборчивость речи с живого микрофона нужно
  проверить пользователю.
- Найден и исправлен баг: parecord требует позиционный путь к файлу, а не
  `--file=...`.

## GUI и интеграции

- GUI запущен в реальном Wayland-сеансе, диалог с моделью прошёл, статус
  модели и голоса отображается корректно.
- Веб-поиск вернул реальные ссылки CachyOS Wiki/Forum/GitHub, модель ответила
  по источникам; `/summarize` создал сводку.
- `wpctl get-volume` вернул текущую громкость; `playerctl` видит Spotify и
  статус Playing.
- Уведомления: `notify-send` в этом сеансе зависает (нет отвечающего демона
  уведомлений), инструмент корректно возвращает ошибку по таймауту. Это
  ограничение окружения, а не приложения.
- Буфер обмена и скриншот не изменялись специально, чтобы не затрагивать
  рабочий сеанс; их логика покрыта unit-тестами.

## Пакетирование

- `makepkg -f --nodeps` успешно собрал `amadeus-git 1.0.0.r10.g01b049a-1`.
- В пакете: `/usr/bin/amadeus`, `/usr/bin/amadeus-gui`, `.desktop` и иконка.
- PKGBUILD проверялся с системным Python и `PYTHONPATH` от venv (зависимости
  сборки не установлены в систему).
